# Staff App (Order Processing) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the staff-facing Telegram Mini App — a live order board (accept/prepare/ready/hand-out/cancel) plus a self-serve stop-list/price tab — backed by a Telegram-to-Supabase-session auth bridge that lets the rest of the backend's existing RLS and Realtime infrastructure do the work unmodified.

**Architecture:** A new Edge Function (`staff-authenticate-telegram`) verifies Telegram `initData`, resolves the caller to a `staff` profile, and mints a Supabase-compatible signed JWT (`sub` = the profile's real `auth.users` id). The staff Mini App (`apps/staff-app/`, a new Vite+TypeScript app structurally mirroring `apps/guest-miniapp/`) uses that JWT as a genuine `supabase-js` session — so `orders`/`order_items`/`order_events` reads, Realtime subscriptions, and `update-order-status` calls all go through the RLS policies and Edge Function that Backend Foundation already shipped, with zero new backend authorization logic beyond the bridge itself.

**Tech Stack:** Deno Edge Functions (existing), Postgres/Supabase RLS + Realtime (existing), Vite + TypeScript (new `apps/staff-app/`, same tooling as `apps/guest-miniapp/`), Vitest, Cloudflare Pages (new hosting target), Web Crypto (`crypto.subtle`) for JWT signing — no new external dependency.

**Spec:** `docs/superpowers/specs/2026-09-02-staff-app-design.md`

## Global Constraints

- Zero paid infrastructure — Supabase Free tier + Cloudflare Pages Free tier only.
- Login to this app is `staff` role only — `business_owner`, `fasdely_operator`, `fasdely_admin` are explicitly rejected by `staff-authenticate-telegram` (see spec's Architecture + Non-Goals sections for why).
- A profile with no `location_id` on file is rejected with a clear error at authentication time, never silently given an empty-board session.

- The two self-serve RPCs (`staff_set_stop`/`staff_set_price`) are not modified — this plan only adds a second UI surface that calls them exactly as the bot already does.
- No client-side router in the Mini App — Telegram `BackButton`/tab-switching drives navigation, matching the guest app's established pattern.
- All DOM text content is inserted as text nodes, never `innerHTML`, except the closed, hardcoded `svgIcon()` icon-path table — the same one exception already established and tested in `apps/guest-miniapp/src/dom.ts`.
- Every new async call that can throw/reject must have its failure path handled explicitly (never leave a button stuck on a loading label, never let a rejection go unhandled) — this project's history (guest Mini App, Tasks 11/14/15) shows this exact bug class recurring across every new call site; each task below that adds a fetch/RPC call must be reviewed with this specifically in mind.

```ts
function base64UrlEncode(bytes: Uint8Array): string {
  let binary = "";
  for (const b of bytes) binary += String.fromCharCode(b);
  return btoa(binary).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

function base64UrlEncodeString(s: string): string {
  return base64UrlEncode(new TextEncoder().encode(s));
}

async function hmacSha256(key: Uint8Array, message: string): Promise<Uint8Array> {
  const cryptoKey = await crypto.subtle.importKey("raw", key, { name: "HMAC", hash: "SHA-256" }, false, ["sign"]);
  const sig = await crypto.subtle.sign("HMAC", cryptoKey, new TextEncoder().encode(message));
  return new Uint8Array(sig);
}

export interface SupabaseSessionClaims {
  sub: string;
  role: "authenticated";
  aud: "authenticated";
  iat: number;
  exp: number;
}

export function buildSupabaseSessionClaims(
  profileId: string,
  nowSeconds: number,
  expiresInSeconds: number
): SupabaseSessionClaims {
  return {
    sub: profileId,
    role: "authenticated",
    aud: "authenticated",
    iat: nowSeconds,
    exp: nowSeconds + expiresInSeconds,
  };
}

export async function signSupabaseSessionJWT(claims: SupabaseSessionClaims, jwtSecret: string): Promise<string> {
  const header = { alg: "HS256", typ: "JWT" };
  const headerEncoded = base64UrlEncodeString(JSON.stringify(header));
  const payloadEncoded = base64UrlEncodeString(JSON.stringify(claims));
  const signingInput = `${headerEncoded}.${payloadEncoded}`;
  const signature = await hmacSha256(new TextEncoder().encode(jwtSecret), signingInput);
  const signatureEncoded = base64UrlEncode(signature);
  return `${signingInput}.${signatureEncoded}`;
}
```

```ts
export interface StaffProfileRow {
  id: string;
  role: string;
  business_id: string | null;
  location_id: string | null;
  status: string;
}

export type StaffAuthResult =
  | { ok: true; profileId: string; businessId: string; locationId: string }
  | { ok: false; reason: "no_matching_profile" | "wrong_role" | "no_location" };

export function resolveStaffSession(profile: StaffProfileRow | null): StaffAuthResult {
  if (!profile || profile.status !== "active") return { ok: false, reason: "no_matching_profile" };
  if (profile.role !== "staff") return { ok: false, reason: "wrong_role" };
  if (!profile.location_id || !profile.business_id) return { ok: false, reason: "no_location" };
  return { ok: true, profileId: profile.id, businessId: profile.business_id, locationId: profile.location_id };
}
```

```ts
import "jsr:@supabase/functions-js/edge-runtime.d.ts";
import { createClient } from "https://esm.sh/@supabase/supabase-js@2";
import { verifyTelegramInitData } from "../_shared/telegramAuth.ts";
import { json, corsHeaders } from "../_shared/http.ts";
import { signSupabaseSessionJWT, buildSupabaseSessionClaims } from "../_shared/supabaseSessionJwt.ts";
import { resolveStaffSession, type StaffProfileRow } from "./logic.ts";

interface AuthBody {
  init_data: string;
}

const SESSION_TTL_SECONDS = 3600;

Deno.serve(async (req: Request) => {
  if (req.method === "OPTIONS") return new Response("ok", { headers: corsHeaders });
  if (req.method !== "POST") return json({ error: "method_not_allowed" }, 405);

  let body: AuthBody;
  try {
    body = await req.json();
  } catch {
    return json({ error: "invalid_json" }, 400);
  }

  const auth = await verifyTelegramInitData(body.init_data, Deno.env.get("TELEGRAM_BOT_TOKEN")!);
  if (!auth.valid || !auth.user) return json({ error: "unauthorized", reason: auth.reason }, 401);

  const db = createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!);

  const { data: profile } = await db
    .from("profiles")
    .select("id, role, business_id, location_id, status")
    .eq("telegram_user_id", auth.user.id)
    .maybeSingle();

  const result = resolveStaffSession(profile as StaffProfileRow | null);
  if (!result.ok) return json({ error: result.reason }, 403);

  const jwtSecret = Deno.env.get("SUPABASE_JWT_SECRET");
  if (!jwtSecret) return json({ error: "server_not_configured" }, 500);

  const nowSeconds = Math.floor(Date.now() / 1000);
  const claims = buildSupabaseSessionClaims(result.profileId, nowSeconds, SESSION_TTL_SECONDS);
  const token = await signSupabaseSessionJWT(claims, jwtSecret);

  return json({
    access_token: token,
    expires_in: SESSION_TTL_SECONDS,
    business_id: result.businessId,
    location_id: result.locationId,
  });
});
```

```ts
import { createClient } from "https://esm.sh/@supabase/supabase-js@2";
import { canStaffTransition, type OrderStatus } from "../_shared/orderStateMachine.ts";
import { json } from "../_shared/http.ts";

Deno.serve(async (req: Request) => {
  if (req.method !== "POST") return json({ error: "method_not_allowed" }, 405);

  const authHeader = req.headers.get("Authorization");
  if (!authHeader) return json({ error: "unauthorized" }, 401);

  const authClient = createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_ANON_KEY")!, {

  });
  const { data: userData, error: userError } = await authClient.auth.getUser();
  if (userError || !userData.user) return json({ error: "unauthorized" }, 401);

  const db = createClient(Deno.env.get("SUPABASE_URL")!, Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!);

  try {
    body = await req.json();
  } catch {
    return json({ error: "invalid_json" }, 400);

    return json({ error: "invalid_transition", from: order.status, to: body.to_status }, 422);
  }

  const { data: updated, error: updateError } = await db
    .from("orders")
    .update({ status: body.to_status })
    .eq("id", order.id)
    .eq("status", order.status)
    .select()
    .maybeSingle();

  if (updateError) return json({ error: "update_failed" }, 500);
  if (!updated) return json({ error: "already_handled" }, 409);

  await db.from("order_events").insert({
    order_id: order.id,
    event_type: body.to_status === "cancelled_by_establishment" ? "cancellation" : "status_change",
    from_status: order.status,
    to_status: body.to_status,
    actor_type: "staff",
    actor_id: userData.user.id,
    reason: body.reason ?? null,
  });

  return json({ order: updated });
});
```

```ts
import { createClient, type SupabaseClient } from "@supabase/supabase-js";
import { getInitData } from "./telegram.ts";

const SUPABASE_URL = "https://rlxbhbdcecrnykwxnqtx.supabase.co";
const SUPABASE_ANON_KEY = "__SUPABASE_ANON_KEY__"; // set to the real publishable anon key before first deploy — see README

export interface StaffSession {
  businessId: string;
  locationId: string;
}

export type AuthenticateResult = { ok: true; session: StaffSession } | { ok: false; error: string };

let client: SupabaseClient | null = null;

export function getSupabaseClient(): SupabaseClient {
  if (!client) throw new Error("Supabase client not initialized — call authenticateAndGetClient() first");
  return client;
}

async function parseJsonSafe(res: Response): Promise<any> {
  try {
    return await res.json();
  } catch {
    return { error: "unknown_error" };
  }
}

export async function authenticateAndGetClient(): Promise<AuthenticateResult> {
  const res = await fetch(`${SUPABASE_URL}/functions/v1/staff-authenticate-telegram`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ init_data: getInitData() }),
  });
  const json = await parseJsonSafe(res);
  if (!res.ok) return { ok: false, error: json.error ?? "unknown_error" };

  client = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);
  await client.auth.setSession({ access_token: json.access_token, refresh_token: "" });

  return { ok: true, session: { businessId: json.business_id, locationId: json.location_id } };
}
```

```ts
export type BoardColumn = "new" | "preparing" | "ready" | "cancelled";

export interface OrderRow {
  id: string;
  order_number: number;
  status: string;
  order_type: "dine_in" | "takeaway";
  comment: string | null;
  total: number;
  created_at: string;
}

export interface OrderItemRow {
  order_id: string;
  product_name_snapshot: string;
  quantity: number;
}

export interface BoardCard {
  id: string;
  orderNumber: number;
  status: string;
  orderType: "dine_in" | "takeaway";
  comment: string | null;
  total: number;
  createdAt: string;
  items: { name: string; quantity: number }[];
}

const COLUMN_STATUSES: Record<BoardColumn, string[]> = {
  new: ["new"],
  preparing: ["accepted", "preparing"],
  ready: ["ready"],
  cancelled: ["cancelled_by_guest", "cancelled_by_establishment"],
};

export function columnForStatus(status: string): BoardColumn | null {
  for (const [column, statuses] of Object.entries(COLUMN_STATUSES) as [BoardColumn, string[]][]) {
    if (statuses.includes(status)) return column;
  }
  return null;
}

export function buildBoardCards(orders: OrderRow[], items: OrderItemRow[]): BoardCard[] {
  const itemsByOrder = new Map<string, { name: string; quantity: number }[]>();
  for (const item of items) {
    const list = itemsByOrder.get(item.order_id) ?? [];
    list.push({ name: item.product_name_snapshot, quantity: item.quantity });
    itemsByOrder.set(item.order_id, list);
  }
  return orders
    .map((o) => ({
      id: o.id,
      orderNumber: o.order_number,
      status: o.status,
      orderType: o.order_type,
      comment: o.comment,
      total: o.total,
      createdAt: o.created_at,
      items: itemsByOrder.get(o.id) ?? [],
    }))
    .sort((a, b) => a.orderNumber - b.orderNumber);
}

export function groupByColumn(cards: BoardCard[]): Record<BoardColumn, BoardCard[]> {
  const grouped: Record<BoardColumn, BoardCard[]> = { new: [], preparing: [], ready: [], cancelled: [] };
  for (const card of cards) {
    const column = columnForStatus(card.status);
    if (column) grouped[column].push(card);
  }
  return grouped;
}

export function upsertOrder(orders: OrderRow[], updated: OrderRow): OrderRow[] {
  const idx = orders.findIndex((o) => o.id === updated.id);
  if (idx === -1) return [...orders, updated];
  const next = [...orders];
  next[idx] = updated;
  return next;
}

export function removeOrder(orders: OrderRow[], id: string): OrderRow[] {
  return orders.filter((o) => o.id !== id);
}
```

```ts
async function callUpdateStatus(orderId: string, toStatus: string, reason?: string): Promise<{ ok: true } | { ok: false; error: string }> {
  const client = getSupabaseClient();
  const { data: sessionData } = await client.auth.getSession();
  const token = sessionData.session?.access_token;
  if (!token) return { ok: false, error: "unauthorized" };

  try {
    const res = await fetch("https://rlxbhbdcecrnykwxnqtx.supabase.co/functions/v1/update-order-status", {
      method: "POST",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
      body: JSON.stringify({ order_id: orderId, to_status: toStatus, reason }),
    });
    const json = await res.json().catch(() => ({ error: "unknown_error" }));
    if (!res.ok) return { ok: false, error: json.error ?? "unknown_error" };
    return { ok: true };
  } catch {
    return { ok: false, error: "network_error" };
  }
}

function formatOrderTime(iso: string): string {

}
```

```ts
import { getSupabaseClient } from "../supabaseClient.ts";
import type { OrderRow } from "../board.ts";

export function subscribeToOrders(
  locationId: string,
  onOrderChange: (event: "insert" | "update" | "delete", order: OrderRow) => void,
  onConnectionChange: (connected: boolean) => void
): () => void {
  const client = getSupabaseClient();
  const channel = client
    .channel(`orders-location-${locationId}`)
    .on("postgres_changes", { event: "INSERT", schema: "public", table: "orders" }, (payload) => {
      onOrderChange("insert", payload.new as OrderRow);
    })
    .on("postgres_changes", { event: "UPDATE", schema: "public", table: "orders" }, (payload) => {
      onOrderChange("update", payload.new as OrderRow);
    })
    .on("postgres_changes", { event: "DELETE", schema: "public", table: "orders" }, (payload) => {
      onOrderChange("delete", payload.old as OrderRow);
    })
    .subscribe((status) => {
      onConnectionChange(status === "SUBSCRIBED");
    });

  return () => {
    client.removeChannel(channel);
  };
}
```

RLS already scopes which rows this subscription can see to the caller's own `location_id` (per `orders_staff_own_location`) — the `locationId` parameter here is only used to namespace the channel name (so a staff member's session never accidentally shares a channel with another location's), not as a filter condition, since RLS is what actually enforces the boundary.

```ts
async function initBoard(content: HTMLElement, session: StaffSession) {
  content.replaceChildren(h("div", {}, ["Загрузка…"]));
  let data;
  try {
    data = await fetchBoardData();
  } catch {
    content.replaceChildren(h("div", { class: "center-screen__desc" }, ["Не удалось загрузить доску. Попробуйте открыть заново."]));
    return;
  }
  boardOrders = data.orders;
  boardItems = data.items;
  renderBoardInto(content, session);

  if (unsubscribeBoard) unsubscribeBoard();
  unsubscribeBoard = subscribeToOrders(
    session.locationId,
    async (event, order) => {
      try {
        if (event === "delete") {
          boardOrders = removeOrder(boardOrders, order.id);
        } else {
          const isNew = !boardOrders.some((o) => o.id === order.id);
          boardOrders = upsertOrder(boardOrders, order);
          if (isNew) {
            triggerHapticNotification();
            playOrderSound();
            const newItems = await fetchItemsForOrder(order.id);
            boardItems = [...boardItems.filter((i) => i.order_id !== order.id), ...newItems];
          }

      } catch {
        // A failed items follow-up (or any other transient failure in this handler)
        // must not crash the whole Realtime callback: the order itself was already
        // patched into boardOrders above (or the catch fired before that point, in
        // which case the order simply isn't reflected until the next event) — either

        // subscription's error unhandled and the board silently stuck.
```

```ts
import { h, formatPrice } from "../dom.ts";
import { getSupabaseClient } from "../supabaseClient.ts";
import { getTelegramUserId } from "../telegram.ts";
import { getSelfServeErrorMessage } from "../errors.ts";
import type { StaffSession } from "../supabaseClient.ts";

interface ProductRow {
  id: string;
  name: string;
  base_price: number;
}

interface OverrideRow {
  product_id: string;
  location_id: string;
  price_override: number | null;
}

interface StopRow {
  scope_id: string;
}

async function fetchSelfServeProducts(session: StaffSession) {
  const client = getSupabaseClient();
  const [{ data: products }, { data: overrides }, { data: stops }] = await Promise.all([
    client.from("products").select("id, name, base_price").eq("business_id", session.businessId).eq("status", "published"),
    client.from("product_location_overrides").select("product_id, location_id, price_override").eq("location_id", session.locationId),
    client.from("stop_list").select("scope_id").eq("business_id", session.businessId).eq("scope_type", "product").eq("location_id", session.locationId).is("lifted_at", null),
  ]);

  const overrideByProduct = new Map((overrides ?? []).map((o: OverrideRow) => [o.product_id, o]));
  const stoppedIds = new Set((stops ?? []).map((s: StopRow) => s.scope_id));

  return (products ?? []).map((p: ProductRow) => ({
    id: p.id,
    name: p.name,
    price: overrideByProduct.get(p.id)?.price_override ?? p.base_price,
    isStopped: stoppedIds.has(p.id),
  }));
}

export async function renderSelfServeScreen(session: StaffSession): Promise<HTMLElement> {
  const telegramUserId = getTelegramUserId();
  const client = getSupabaseClient();
  const list = h("div", { class: "scroller" }, [h("div", {}, ["Загрузка…"])]);

  async function refresh() {
    let products;
    try {
      products = await fetchSelfServeProducts(session);
    } catch {
      list.replaceChildren(h("div", { class: "center-screen__desc" }, ["Не удалось загрузить меню. Потяните экран, чтобы обновить, или откройте заново."]));
      return;
    }
    list.replaceChildren(
      ...products.map((p) => {
        const toggle = h("div", { class: `self-serve-row__toggle${p.isStopped ? " is-stopped" : ""}` }, [
          p.isStopped ? "Включить" : "Стоп",
        ]);
        toggle.addEventListener("click", async () => {
          if (!telegramUserId) return;
          toggle.textContent = "…";
          try {
            const { error } = await client.rpc("staff_set_stop", {
              p_telegram_user_id: telegramUserId,
              p_location_id: session.locationId,
              p_product_id: p.id,
              p_stop: !p.isStopped,
            });
            if (error) alert(getSelfServeErrorMessage(error.message));
          } catch {
            alert(getSelfServeErrorMessage("network_error"));
          }
          refresh();
        });

        const priceEl = h("span", { class: "self-serve-row__price" }, [formatPrice(p.price)]);
        priceEl.addEventListener("click", async () => {
          const input = prompt("Новая цена, ₽:", String(p.price));
          if (!input || !input.trim()) return;
          const newPrice = Number(input.trim().replace(",", "."));
          if (!Number.isFinite(newPrice) || newPrice < 0) {
            alert("Некорректная цена.");
            return;
          }
          if (!telegramUserId) return;
          try {
            const { error } = await client.rpc("staff_set_price", {
              p_telegram_user_id: telegramUserId,
              p_location_id: session.locationId,
              p_product_id: p.id,
              p_new_price: newPrice,
            });
            if (error) alert(getSelfServeErrorMessage(error.message));
          } catch {
            alert(getSelfServeErrorMessage("network_error"));
          }
          refresh();
        });

        return h("div", { class: "self-serve-row" }, [
          h("span", { class: "self-serve-row__name" }, [p.name]),
          priceEl,
          toggle,
        ]);
      })
    );
  }

  await refresh();
  return h("div", {}, [list]);
}
```
